## Commandes et outils
**Invite de commandes Windows (CMD), dans une machine virtuelle de simulation**
- `cd` : change de dossier.
- `dir` : liste le contenu d'un dossier. `dir /a` : affiche aussi les fichiers et dossiers cachés. `dir /s` : cherche dans les sous-dossiers, ce qui permet de retrouver un fichier par son nom.
- `type` : affiche le contenu d'un fichier (équivalent de `cat` sous Linux).
- `whoami` : affiche l'utilisateur connecté.
- `hostname` : affiche le nom de la machine.
- `systeminfo` : affiche les informations détaillées du système.
- `ipconfig` : affiche la configuration réseau (adresse IP).

**Sécurité du système d'exploitation, sur une machine Linux de simulation**
- `ssh` : se connecter à distance à une machine avec un nom d'utilisateur.
- `ls` et `cat` : lister et lire des fichiers.
- `history` : affiche les commandes tapées précédemment, qui peuvent révéler un mot de passe laissé par un utilisateur.
- `su - root` : passer en administrateur (root) quand on connaît son mot de passe.

**Notions**
- Triade de la sécurité : confidentialité (confidentiality), intégrité (integrity), disponibilité (availability).
- Problèmes courants : mots de passe faibles (authentication), autorisations de fichiers trop larges (file permissions), programmes malveillants (malware : cheval de Troie, rançongiciel).
- Matériel (hardware) et logiciel (software) : le système d'exploitation fait le lien entre les deux.
