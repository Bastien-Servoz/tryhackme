## Pourquoi
Comprendre comment les données sont stockées et interrogées. Les bases de données sont partout (sites web, applications) et reviennent en programmation web comme en cybersécurité.

## Commandes et outils
- `SELECT` : choisit les données à afficher (les colonnes).
- `FROM` : indique la source des données (la table).
- `WHERE` : filtre les enregistrements selon une condition.
- `ORDER BY` : trie les résultats.
- MySQL : système de gestion de base de données utilisé pour s'exercer, sur une machine virtuelle avec des données fictives.

## Ce que j'ai compris / ce qui reste flou
- Une base de données range les données dans des tableaux : les colonnes décrivent le type d'information, chaque ligne est un enregistrement.
- SQL sert à interroger ces données de façon précise, plutôt que de les chercher à la main.
- Une requête se construit en combinant les quatre éléments : choisir (`SELECT`), la source (`FROM`), le filtre (`WHERE`) et le tri (`ORDER BY`).
- Rien de flou à signaler.
