## Commandes et outils
- SSH : se connecter à une machine Linux à distance. Il faut trois éléments : l'adresse IP, le nom d'utilisateur et le mot de passe.
- `--help` : affiche les arguments (options) disponibles d'une commande.
- `ls -a` : affiche aussi les fichiers cachés.
- `touch` : crée un fichier vide.
- `mkdir` : crée un dossier.
- `cp` : copie un fichier.
- `mv` : déplace ou renomme un fichier.
- `rm` : supprime un fichier.
- `/etc`, `/var` : répertoires communs de Linux, où je peux me déplacer avec `cd`.
- `su -l` : se connecter en tant qu'un autre utilisateur.
